# AutoPulse — AI-Powered Used Car Valuation & Deal Advisor for Pakistan

AutoPulse predicts fair market listing prices (PKR) for used cars in Pakistan using machine learning and flags whether a listing is a **Good Deal**, **Fair Price**, or **Overpriced**.

## Repository Structure
- `data/raw/` — Raw Kaggle CSV datasets (gitignored)
- `data/processed/` — Cleaned, deduplicated datasets generated by `src/data/clean.py` (gitignored)
- `notebooks/` — Exploratory Data Analysis (EDA) and visualization notebooks
- `src/data/` — Dataset audit (`audit.py`) and cleaning/parsing pipeline (`clean.py`)
- `src/features/` — Leakage-free feature engineering pipeline
- `src/models/` — Model training, benchmarking (4 models), and evaluation
- `backend/` — FastAPI inference service exposing `/predict`
- `mobile_app/` — AutoPulse mobile client
- `reports/evidence/` — Audit logs, preprocessing attrition tables, and evaluation metrics
- `reports/figures/` — High-resolution (300 DPI) EDA and model comparison charts

## Quickstart Setup
    git clone [https://github.com/Faiz-Ul-Hassan-Khalil/autopulse.git](https://github.com/Faiz-Ul-Hassan-Khalil/autopulse.git)
    cd autopulse
    git checkout dev
    python3 -m venv .venv
    source .venv/bin/activate
    pip install -r requirements.txt

Place the raw Kaggle CSVs into `data/raw/` and run:

    python src/data/clean.py
